# Angebots-Studio · Michaela Raninger Fotografie

Web-App zum Erstellen und Versenden von Hochzeitsangeboten (PDF, WhatsApp, HTML-E-Mail).
Läuft im Browser auf Handy und PC und lässt sich als App installieren. Gehostet über GitHub Pages.

## Schnellstart

1. Kunden-App öffnen → am Handy erscheint die Anleitung „Als App speichern“.
2. Design wählen → Paar & Datum → Fotos → Inhalte → Senden.
3. Änderungen an Texten, Preisen und Designs macht der Admin in der Admin-App und klickt „Veröffentlichen“.

## Hinweis zur Schrift „The Seasons“

`assets/fonts/TheSeasons-Light.ttf` ist eine kommerzielle Schrift. Da das Repo öffentlich ist, ist die Datei herunterladbar.
Bitte prüfen, ob die Lizenz Web-Einbettung erlaubt. Alternative: In der Admin-App je Design „Cormorant Garamond“ (frei) wählen.
